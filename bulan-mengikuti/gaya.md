# Gaya: Jalan Desa Malam 3D (racikan dari Sejarah 3D Sinematik, set C "malam biru + lampu hangat")
- Kamera: perspektif FOV 32 (16:9), ikut mobil dari samping/serong rendah, goyang genggam halus; crane naik ke tampilan atas untuk diagram garis pandang
- Cahaya: Bulan purnama rendah (±11°) dari kiri-belakang mobil, biru perak; lampu mobil & jendela rumah kuning hangat; isi dingin dari sisi kamera
- Palet: langit navy #060D1A→#2A4466 · kabut #22344E · Bulan #F4F1E6 · mobil merah #B23A2A · lampu hangat #FFC86B (aksen teks) · garis pandang cyan #7FE3FF (aksen dingin)
- Bahan: aspal bertekstur + marka putus-putus, sawah berair memantulkan langit, pohon kelapa & pohon rimbun siluet, gunung api di cakrawala dimakan kabut
- Tipografi: Instrument Serif (judul 150 px, label 48 px) + Onest 800 (subtitle 52 px), tanpa kotak, bayangan berlapis + selubung gelap
- Subtitle: per kata, polos, di bawah (±0,87H), kata kunci kuning hangat
- Tanda tangan gerak: garis pandang cyan dari mata ke benda — ke pohon garisnya berputar cepat, ke Bulan garisnya tetap sejajar
- Suara: VO hangat, ramah untuk SMP, tempo sedang · efek: deru mobil lewat, whoosh pohon, denting saat garis pandang muncul · ambience jangkrik malam pelan
